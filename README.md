# 🪽 Icarus: A Banglish Mini Programming Language

> 🎓 Compiler Design Lab project, Department of CSE, Daffodil International University · Team of 5

Icarus is a small interpreted programming language whose keywords are written in **Banglish** (Bangla words typed in English letters). It is built with **Flex** (lexical analysis) and **Bison** (parsing) in **C**, and gives hands-on experience with the core stages of a compiler: tokenizing, parsing with grammar rules, and executing statements.

---

## 🔤 Keywords

| Icarus keyword | Meaning (Bangla) | Equivalent |
|---|---|---|
| `dhor` | ধর (take / let) | variable declaration |
| `lekh` | লেখ (write) | print |
| `por` | পড় (read) | input |
| `jodi` | যদি (if) | `if` |
| `nahole` | নাহলে (otherwise) | `else` |
| `jokhon` | যখন (when / while) | `while` |
| `ejonne` | এজন্যে (for this) | `for` |

Every statement ends with a question mark `?`, and `{ }` groups statements into a block.

---

## ✍️ Example

```
dhor x = 5?
lekh x?
lekh 42?
```

Output:

```
Starting Icarus interpreter...
x = 5
5
42
```

To try `por?` (input), run `./icarus` without a file and type the program in line by line.

A copy of this program is in [`demo.txt`](demo.txt).

## ▶️ How to build and run

You need **Flex**, **Bison** and **GCC**.

```bash
git clone https://github.com/inglorious-star/Icarus-Banglish-Programming-Language.git
cd Icarus-Banglish-Programming-Language

bison -d icarus.y          # creates icarus.tab.c and icarus.tab.h
flex icarus.l              # creates lex.yy.c
gcc icarus.tab.c lex.yy.c -o icarus

./icarus < demo.txt
```

On Windows, the prebuilt `icarus.exe` is included: run `icarus.exe < demo.txt`.

## 🎯 Project goals (from the proposal)

- **Language syntax and semantics:** clear rules for statements, expressions and control flow
- **Lexical analysis with Flex:** tokenize source code into keywords, identifiers, operators and numbers
- **Syntax analysis with Bison:** grammar rules that parse token sequences
- **Symbol table management:** track variables and enforce declaration before use
- **Interpretation:** execute the parsed program
- **Error handling:** report syntax and semantic errors

## 🚧 Current status and limitations

The current version implements the keywords, statement structure and grammar above. Some planned features are not built yet:

- Only integer values, and only one variable value is stored at a time (no full symbol table yet)
- Arithmetic (`+ - * / %`) and comparison operators are planned but not yet in the grammar
- `jodi`, `nahole`, `jokhon` and `ejonne` are parsed, but their conditions are not evaluated yet (the inner statement simply runs once)
- Comments (`**`) are planned but not yet supported
